# Environment variables

Generated by `sip-source env` from the code. Print the same list from the image with:

```bash
docker run --rm ntuxa76/sip-source:0.9 env
```

## How to set them

- **Docker Compose:** add them under `environment:` of the `sip-source` service in `docker-compose.yml`, or put them in `.env` and reference them there.
- **docker run:** pass each one with `-e NAME=value`.
- **Secrets:** the passwords below also accept a `_FILE` variant, for example `SS_DB_PASSWORD_FILE=/run/secrets/db`, which reads the value from that file.

Only `SS_DB_HOST`, `SS_DB_USER` and `SS_DB_PASSWORD` are required. Everything else has a working default.

Storage isn't set here. Captured data goes to the built-in Local file storage under `SS_DATA_DIR` until you add a ClickHouse server under **Admin → Storage**.

## Startup settings

Read once when the container starts. Changing one means restarting the container.

### Database

| Variable | Default | Required | Description |
|---|---|---|---|
| `SS_DB_HOST` | – | yes | MariaDB host name or IP. |
| `SS_DB_USER` | – | yes | MariaDB user. |
| `SS_DB_PASSWORD` | – | yes | MariaDB password. SS_DB_PASSWORD_FILE reads it from a file instead (Docker secrets). |
| `SS_DB_NAME` | `voip_panel` | no | Database name. It must already exist; the tables are created on first start. |
| `SS_DB_PORT` | `3306` | no | MariaDB port. |
| `SS_DB_URL` | – | no | Replaces all SS_DB_* above, e.g. mysql://user:pass@host:3306/voip_panel. SS_DB_URL_FILE also works. |
| `SS_DB_SSL_MODE` | `preferred` | no | disabled, preferred, required, verify_ca or verify_identity. |
| `SS_DB_MAX_CONNECTIONS` | `10` | no | Connection pool size. |
| `SS_DB_CONNECT_RETRIES` | `60` | no | Attempts to reach MariaDB at startup before giving up. |
| `SS_DB_CONNECT_RETRY_SECONDS` | `2` | no | Wait between those attempts. |

### Storage

| Variable | Default | Required | Description |
|---|---|---|---|
| `SS_DATA_DIR` | `/data` | no | Where the Local file storage keeps its data. Mount a volume here. |
| `SS_LOCAL_ENGINE` | `/usr/local/bin/clickhouse` | no | The storage engine the Local file storage runs. Only change it when running outside the image. |
| `SS_LOCAL_PORT` | `8124` | no | Port on 127.0.0.1 the Local file storage engine listens on inside the container. |

### Network

### First start and secrets

| Variable | Default | Required | Description |
|---|---|---|---|
| `SS_ADMIN_USERNAME` | `admin` | no | Name of the first administrator. |
| `SS_ADMIN_PASSWORD` | – | no | Creates the administrator at startup and skips the first-run screen. SS_ADMIN_PASSWORD_FILE also works. |

|---|---|---|---|
