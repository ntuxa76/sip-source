# Environment variables

Generated by `vpd env`. Only the three variables marked required must be set.

## Process

Read once at startup.

| Variable | Default | Required | Description |
|---|---|---|---|
| `VP_DB_HOST` | – | yes | MariaDB host |
| `VP_DB_USER` | – | yes | MariaDB user |
| `VP_DB_PASSWORD` | – | yes | MariaDB password. VP_DB_PASSWORD_FILE reads it from a file (Docker secrets) |
| `VP_DB_NAME` | `voip_panel` | no | Database name. It must already exist |
| `VP_DB_PORT` | `3306` | no | MariaDB port |
| `VP_DB_URL` | – | no | Replaces all VP_DB_* above, e.g. mysql://user:pass@host:3306/voip_panel |
| `VP_DB_SSL_MODE` | `preferred` | no | disabled, preferred, required, verify_ca or verify_identity |
| `VP_DB_MAX_CONNECTIONS` | `10` | no | Connection pool size |
| `VP_DB_CONNECT_RETRIES` | `60` | no | Attempts to reach MariaDB at startup |
| `VP_DB_CONNECT_RETRY_SECONDS` | `2` | no | Wait between those attempts |
| `VP_LISTEN` | `0.0.0.0:8080` | no | Address and port to serve on |
| `VP_ADMIN_USERNAME` | `admin` | no | Name of the first administrator |
| `VP_ADMIN_PASSWORD` | – | no | Creates the administrator at startup and skips the first-run screen. VP_ADMIN_PASSWORD_FILE also works |
| `VP_SETUP_TOKEN` | – | no | If set, the first-run screen asks for this token. Use it when the port is reachable by others before setup |
| `VP_SECRET_KEY` | – | no | Encrypts storage passwords in MariaDB. Keep it stable: changing it makes saved passwords unreadable |
| `VP_TRUST_PROXY` | `false` | no | Take the client address from X-Forwarded-For. Only behind a proxy you control |
| `VP_LOG_LEVEL` | `info` | no | trace, debug, info, warn or error |
| `VP_LOG_FORMAT` | `text` | no | text or json |

## Application

Each of these can also be changed on the Settings page and is then saved in MariaDB. A value set in the environment takes priority and appears locked in the UI.

### Branding

| Variable | Default | Description |
|---|---|---|
| `VP_APP_NAME` | `voip-panel` | Application name. Shown in the sidebar, the login page and the browser tab. |
| `VP_ACCENT_COLOR` | – | Accent color. CSS color for buttons and highlights, e.g. #2a78d6. Empty keeps the default. |
| `VP_DEFAULT_THEME` | `system` | Default theme. Used until a user picks their own. |
| `VP_LOGIN_MESSAGE` | – | Login message. Text shown under the sign-in form. |
| `VP_BANNER_TEXT` | – | Banner. One line shown at the top of every page, e.g. Staging system. |

### Time

| Variable | Default | Description |
|---|---|---|
| `VP_DEFAULT_TZ` | `Asia/Baghdad` | Default time zone. IANA name. Users can override it in their preferences. |
| `VP_TIME_ZONES` | `Asia/Baghdad,UTC,Europe/London,Asia/Dubai` | Time zones offered. Comma-separated list for the time picker. |

### Dashboards

| Variable | Default | Description |
|---|---|---|
| `VP_HOME_DASHBOARD` | `overview` | Home dashboard. UID of the dashboard shown on the Home page. |
| `VP_DEFAULT_RANGE` | `now-6h` | Default time range. Used when a dashboard or URL does not set one, e.g. now-1h. |
| `VP_DEFAULT_REFRESH_SECONDS` | `30` | Default auto refresh (s). 0 turns it off. |
| `VP_SHARED_CROSSHAIR` | `false` | Link charts on hover. When on, pointing at one chart shows the crosshair on every chart of the dashboard. Users and dashboards can override it. |
| `VP_CHART_MAX_POINTS` | `1500` | Max points per chart. Upper limit for automatic bucket sizes. |
| `VP_CHART_TOP_SERIES` | `8` | Max series per chart. Extra values fold into "other". Colors stay distinct up to 8. |
| `VP_SETTLE_WINDOW_SECONDS` | `300` | Settle window (s). Newer buckets are drawn dashed or hatched. |
| `VP_DASHBOARD_VERSIONS_KEEP` | `20` | Versions kept per dashboard. Older versions are removed when a dashboard is saved. |

### Search

| Variable | Default | Description |
|---|---|---|
| `VP_SEARCH_DEFAULT_RANGE` | `now-24h` | Default search range. Used when no time range is given. |
| `VP_SEARCH_PAGE_SIZE` | `100` | Rows per page. Default number of rows in the results table. |
| `VP_SEARCH_MAX_PAGE_SIZE` | `500` | Max rows per page. Upper limit for one results page. |
| `VP_SEARCH_FACET_SIZE` | `12` | Values per filter. How many values each filter list shows. |
| `VP_EXPORT_MAX_ROWS` | `100000` | CSV export limit. Maximum rows in one export. |

### Live capture

| Variable | Default | Description |
|---|---|---|
| `VP_LIVE_ENABLED` | `false` | Enable live capture. Off by default so it uses no resources. Even when on, a stream only runs while someone has pressed Start. |
| `VP_LIVE_MAX_SESSIONS` | `20` | Max concurrent streams. Further viewers get an error. |
| `VP_LIVE_IDLE_MINUTES` | `30` | Stop stream after (min). A stream is closed automatically after this long. |
| `VP_LIVE_TICK_MS` | `1000` | Update interval (ms). How often a stream sends new messages. |

### SQL

| Variable | Default | Description |
|---|---|---|
| `VP_SQL_ENABLED` | `true` | Enable SQL. Turns the workbench and SQL panels on or off for everyone. |
| `VP_SQL_TIMEOUT_SECONDS` | `120` | Query timeout (s). Applied to queries sent to ClickHouse. |
| `VP_SQL_MAX_ROWS` | `10000` | Max result rows. Results are cut off at this size. |

### Privacy

| Variable | Default | Description |
|---|---|---|
| `VP_MASK_KEEP_DIGITS` | `4` | Digits left visible when masked. For users without the Unmask numbers permission. |

### Sessions & passwords

| Variable | Default | Description |
|---|---|---|
| `VP_SESSION_IDLE_MINUTES` | `30` | Idle timeout (min). Sign out after this long with no requests. |
| `VP_SESSION_ABSOLUTE_HOURS` | `12` | Absolute timeout (h). Sign out this long after login, regardless of activity. |
| `VP_PASSWORD_MIN_LENGTH` | `12` | Minimum password length. Applies when a password is set. |
| `VP_LOGIN_MAX_ATTEMPTS` | `5` | Failed logins before lockout. Per account. |
| `VP_LOGIN_LOCKOUT_MINUTES` | `15` | Lockout duration (min). How long an account stays locked. |
| `VP_COOKIE_NAME` | `vp_session` | Session cookie name. Change it when several instances share a host name. Takes effect after a restart. |
| `VP_COOKIE_SECURE` | `auto` | Secure cookie. auto follows the X-Forwarded-Proto header set by a TLS proxy. |

### Audit

| Variable | Default | Description |
|---|---|---|
| `VP_AUDIT_RETENTION_DAYS` | `365` | Audit retention (days). Older audit events are deleted daily. |

### Demo data

| Variable | Default | Description |
|---|---|---|
| `VP_DEMO_DAYS` | `7` | Days of demo traffic. More days use more memory. Takes effect after a restart. |
| `VP_DEMO_SCALE` | `1` | Demo traffic scale. 1 is about 25,000 calls a day and 200 MB of memory for 7 days. Takes effect after a restart. |
| `VP_DEMO_SUBSCRIBERS` | `9600` | Demo subscribers. Size of the generated subscriber pool. Takes effect after a restart. |
